# 远控驱动开关

用于 UU远程、ToDesk 和向日葵的 Windows 便携工具。需要排查远控虚拟键鼠对游戏输入的影响时，可以暂时停用已适配的远控组件，用完后从本机备份恢复。

[下载 Windows x64 便携版](https://github.com/drydraft/RemoteDriverSwitch/releases/latest) · [使用说明](./使用说明.md)

支持 Windows 10 2004（19041）及以上、Windows 11 的 x64 版本。解压后运行 `远控驱动开关.exe`，允许管理员权限。

## 使用

1. 启动后等待自动扫描。软件区分别显示客户端进程和受管服务状态，驱动和设备状态在下方列表查看。
2. 在能直接操作电脑时点击「禁用并重启（游戏）」。工具先保存原始配置，再停用已识别的登录启动项、停止远控服务和进程，最后处理已适配的设备和驱动。切换会中断相关远控连接。
3. 重启并登录原账户，工具会自动打开并核验。若已识别的远控登录启动项重新出现，会自动补处理并尝试关闭对应客户端，这一步无需再次重启。仍有异常时，界面会说明原因。
4. 需要远控时，用保存备份的 Windows 账户点击「恢复并重启（远控）」，按本机备份恢复原来的配置。

关闭窗口后工具会驻留托盘，空闲时不会持续扫描设备或进程。游戏中的实际鼠标手感请在切换后自行验证。

## 检查和安装更新

工具启动时以及运行期间每隔 6 小时会检查 GitHub 上的正式版本，也可以在主窗口或托盘菜单手动检查。发现新版时，点击托盘通知打开工具，然后点「立即更新」。工具会下载并校验便携包、替换 EXE，再自动打开新版。Windows 无需重启。

v1.2.0 及更早版本没有内置安装更新的功能，需要手动升级到 v1.2.1 或更新版本一次。

## 构建和测试

在仓库根目录打开 PowerShell。构建脚本使用 Windows 自带的 .NET Framework 编译器，生成便携 EXE 和模拟测试程序。

```powershell
.\build.ps1
.\build\RemoteDriverSwitch.Tests.exe
```

便携 EXE 位于 `dist`。自动测试用模拟设备和服务运行，无需切换本机远控状态。
